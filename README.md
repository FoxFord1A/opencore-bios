# OpenCore BIOS для OpenComputers

Компактный BIOS-загрузчик для Lua-компьютеров из мода **OpenComputers**. Он пытается запустить `/init.lua` на файловой системе, адрес которой сохранён в EEPROM; если она недоступна или не загружается, ищет рабочую файловую систему среди остальных подключённых устройств.

## Возможности

- сначала пробует файловую систему, выбранную BIOS как загрузочную;
- при ошибке ищет `/init.lua` на других файловых системах и запоминает успешный адрес;
- привязывает первый доступный GPU к первому экрану;
- сообщает причину сбоя загрузки;
- установщик сохраняет резервную копию текущего EEPROM, проверяет лимит 4096 байт, требует ввести `INSTALL` и проверяет результат прошивки.

Это BIOS-загрузчик, а не операционная система: для загрузки на диске должна быть установленная ОС, например OpenOS, с файлом `/init.lua`.

## Установка

### Через Internet Card

В OpenOS с подключённой Internet Card можно скачать оба файла прямо с GitHub:

```sh
wget https://raw.githubusercontent.com/FoxFord1A/opencore-bios/main/bios.lua /tmp/bios.lua
wget https://raw.githubusercontent.com/FoxFord1A/opencore-bios/main/install.lua /tmp/install.lua
lua /tmp/install.lua /tmp/bios.lua
```

### С локального носителя

1. Скопируйте `bios.lua` и `install.lua` на файловую систему компьютера OpenComputers (например, на дискету или жёсткий диск).
2. В OpenOS запустите установщик, указав путь к `bios.lua`, например:

   ```sh
   lua /mnt/floppy/install.lua /mnt/floppy/bios.lua
   ```

   Путь зависит от того, куда смонтирован носитель. Если `lua` не найден, проверьте, что компьютер действительно загрузил OpenOS.
3. Установщик создаст `opencore-bios-backup-<время>.lua` в текущей папке. Введите `INSTALL`, только если хотите заменить текущий BIOS.
4. Перезапустите компьютер. При желании сохраните файл резервной копии отдельно.

Перед установкой убедитесь, что у вас есть рабочий способ восстановить BIOS (например, EEPROM Writer или другой компьютер OpenComputers с EEPROM). Не отключайте питание во время прошивки.

## Восстановление

Загрузитесь с резервного носителя/EEPROM Writer, затем запишите сохранённый файл резервной копии обратно в EEPROM. Можно также вернуть стандартный Lua BIOS OpenComputers.

## Настройка загрузочного диска

BIOS запоминает адрес файловой системы, с которой успешно загрузился `/init.lua`. Если носитель удалён или загрузка не удалась, BIOS просканирует остальные файловые системы и выберет первую рабочую.

## Проверка размера

EEPROM OpenComputers хранит максимум 4 KiB кода. Установщик откажется прошивать файл больше 4096 байт. Быстрая проверка в Linux/macOS:

```sh
wc -c bios.lua
```

## Разработка и тесты

`tests/test_boot.lua` запускает BIOS под обычным Lua с имитацией компонентов OpenComputers. Запуск:

```sh
lua tests/test_boot.lua
luac -p bios.lua install.lua tests/test_boot.lua
```

## Совместимость

Рассчитано на Lua architecture OpenComputers и EEPROM с обычным 4 KiB лимитом. Официальная документация: [EEPROM](https://ocdoc.cil.li/item:eeprom) и [Custom OSes](https://ocdoc.cil.li/tutorial:custom_oses).
