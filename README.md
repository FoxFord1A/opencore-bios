# OpenCore BIOS для OpenComputers

Загрузчик для **OpenComputers Lua architecture** с текстовым логотипом, меню выбора загрузочного устройства и страницей настроек. Код разделён на два этапа: компактный BIOS хранится в EEPROM, а модуль меню — на текущем загрузочном диске как `/ocbios.lua`.

## Возможности

- текстовая заставка и меню загрузки;
- отображение всех файловых компонентов, включая RAID-тома без `/init.lua`;
- пометка загрузочных устройств и data-only томов; запуск разрешён только для тома с `/init.lua`;
- выбор устройства стрелками и запуск клавишей Enter;
- клавиша `S` открывает настройки;
- настройка диска по умолчанию, тайм-аута автозагрузки (0–10 секунд), звукового сигнала и логотипа;
- сохранение настроек в EEPROM;
- резервные копии старого EEPROM-кода и прежнего `/ocbios.lua`;
- если модуль меню отсутствует, stage-1 пытается загрузить обычный `/init.lua`.

Это загрузчик, не операционная система. На загрузочном диске нужна ОС с `/init.lua`, например OpenOS. RAID и другие файловые системы с данными, но без `/init.lua`, теперь тоже показаны в меню как `[data/no init]` — выбрать их для загрузки можно, но они не являются загрузочными, пока на них не установлена ОС. Нужны GPU и экран для меню; без них stage-1 пытается запустить обычную ОС.

## Установка из OpenOS

Нужна Internet Card для загрузки файлов или их можно перенести на диск вручную. Команды используют закреплённую версию `v1.3.2`:

```sh
wget https://raw.githubusercontent.com/FoxFord1A/opencore-bios/v1.3.2/bios.lua /tmp/bios.lua
wget https://raw.githubusercontent.com/FoxFord1A/opencore-bios/v1.3.2/bootmgr.lua /tmp/bootmgr.lua
wget https://raw.githubusercontent.com/FoxFord1A/opencore-bios/v1.3.2/install.lua /tmp/install-v1.3.2.lua
lua /tmp/install-v1.3.2.lua
```

Установщик запросит:

1. путь к EEPROM BIOS — введите `/tmp/bios.lua`;
2. путь к модулю меню — введите `/tmp/bootmgr.lua`;
3. подтверждение — введите `INSTALL`, только если хотите продолжить.

Установщик скопирует модуль меню на текущую загрузочную файловую систему в `/ocbios.lua`, сохранит резервные копии, проверит, что BIOS не превышает 4096 байт, затем прошьёт и перепроверит EEPROM. Не удаляйте `/ocbios.lua`, если хотите пользоваться меню.

После перезапуска: стрелками выберите диск, Enter — загрузка, `S` — настройки. По умолчанию BIOS ждёт 5 секунд, затем запускает диск по умолчанию или первый доступный. Тайм-аут `0` выключает автозагрузку.

## Восстановление и откат

Stage-1 автоматически возвращается к обычной загрузке `/init.lua`, если не найдёт `/ocbios.lua`. Для возврата старого BIOS используйте резервный файл `opencore-bios-backup-<время>.lua` из текущей папки OpenOS и восстановите его через EEPROM Writer или другое доступное средство прошивки. Если ранее существовал `/ocbios.lua`, установщик сохраняет его как `opencore-manager-backup-<время>.lua`.

Не отключайте питание во время прошивки. Перед установкой убедитесь, что сможете восстановить EEPROM.

## Разработка и тесты

```sh
lua tests/test_boot.lua
lua tests/test_menu.lua
lua tests/test_install_v13.lua
lua tests/test_install_success.lua
luac -p bios.lua bootmgr.lua install.lua tests/test_boot.lua tests/test_menu.lua tests/test_install_v13.lua tests/test_install_success.lua
wc -c bios.lua
```

Stage-1 должен быть не больше **4096 байт**. Меню загружается с системного диска и ограничением EEPROM не связано.

## Совместимость

Требуются OpenComputers Lua architecture, EEPROM, файловая система и (для интерфейса) GPU с экраном. См. [документацию EEPROM](https://ocdoc.cil.li/item:eeprom) и [руководство по пользовательским ОС](https://ocdoc.cil.li/tutorial:custom_oses).
